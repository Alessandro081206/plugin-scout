Der Nutzer sucht ein Claude-Code-Plugin für: **$ARGUMENTS**

Falls oben nichts steht, frag kurz nach, wofür er ein Plugin sucht, und mach dann weiter.

Nutze den Skill `plugin-scout`:
1. Übersetze den Wunsch in gute Suchbegriffe (Deutsch **und** Englisch, die meisten Plugins sind auf Englisch beschrieben).
2. Suche auf GitHub und im Web (Marketplaces, Reddit, Hacker News, Awesome-Listen), wie im Skill beschrieben.
3. Filtere nach den Qualitätsregeln und sortiere schon installierte Plugins aus.
4. Stell **3–5** passende Plugins als Plugin-Karten vor, **das beste zuerst**. Davor ein Satz wie: "Für <Wunsch> hab ich das hier gefunden:"
5. Ist nichts Gutes dabei, sag das ehrlich und schlag vor, wie man die Suche anders formulieren könnte.

Antworte auf Deutsch, locker und ohne Fachchinesisch.
