Vergleiche diese Plugins: **$ARGUMENTS**

Steht nichts oder nur ein Plugin da, frag nach dem zweiten oder schlag passende Alternativen zum ersten vor. Namen ohne Repo: zuerst das richtige GitHub-Repo finden und sagen, welches du meinst.

Nutze den Skill `plugin-scout` (Profil, Dateien lesen, Schnell-Check).

## Für jedes Plugin herausfinden
- Was es kann (README, Befehle, Skills)
- Wie man es benutzt (Befehle eintippen oder automatisch)
- Was es braucht (Konten, API-Schlüssel, Kosten, Programme wie Python/Node)
- Ampel aus dem Schnell-Check (Hooks, MCP, Herausgeber, Sterne)
- Wie aktiv es gepflegt wird, Sterne, was Leute in Foren und Issues sagen
- Ob es schon installiert ist

## Ergebnis
In der Sprache des Nutzers, einfach (Überschriften und Beschriftungen unten übersetzen):

```
## ⚖️ <A> vs. <B>

| | <A> | <B> |
|---|---|---|
| Was es macht | | |
| Am besten für | | |
| Einfach zu benutzen | ⭐⭐⭐ | ⭐⭐ |
| Braucht extra | | |
| Kosten | | |
| Gepflegt | | |
| Sicherheit | 🟢 | 🟡 |

**<A> ist besser, wenn …** <1–2 Sätze>
**<B> ist besser, wenn …** <1–2 Sätze>

### 🏁 Für dich: <A oder B>
<2 Sätze Begründung mit Bezug aufs Profil + Install-Befehle des Gewinners>
```

Sind beide schwach, sag das und schlag eine bessere Alternative vor.
